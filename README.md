## 📖 About the Project

AlphaStore is a full-stack e-commerce web application inspired by Amazon and Flipkart. It provides an interactive shopping experience with product browsing, filtering, cart management, discount coupons, checkout, and order history.

## ✨ Features

- Product listings and category navigation
- Product filtering and quick-view modals
- Shopping cart with persistent storage
- Promotional coupon discounts
- Multi-step checkout process
- Order history and invoice generation
- Responsive user interface

## 🛠️ Tech Stack

- **Backend:** Node.js, Express.js
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Typography:** Roboto
- **Development Tools:** npm, Git, GitHub

## 🚀 Run Locally

Make sure Node.js and npm are installed.

```bash
cd backend
npm install
npm start
```

Open your browser at:

http://localhost:5000
